# Append to Chosen Note
This is a JavaScript template for use with the [Templater plugin](https://community.obsidian.md/plugins/templater-obsidian) for Obsidian, created with AI (I think I used Copilot?). 

## To Use:
Download a copy of the template and store it in your folder of choice in your Obsidian notebook, for example:
<img width="904" height="708" alt="image" src="https://github.com/user-attachments/assets/5256174c-f0d9-4b47-9324-6b8e9649c392" />

From there, choose a keystroke to trigger the template:
<img width="1421" height="551" alt="image" src="https://github.com/user-attachments/assets/d0771b9e-b82a-4d49-a869-7d94ed71c87c" />

The slide deck above includes additional screenshots of how to use the template once the file has been created and stored. 

## New to Templater?
If you're new to Templater, check out SilentVoid13's repot, [DEMO: How to setup and run your first Templater JS "script"](https://github.com/SilentVoid13/Templater/discussions/187), or explore the [Templater Docs](https://community.obsidian.md/plugins/templater-obsidian).
