# Data Project Template

Here is an example project structure for use in any IDE. 
```
data-project-template/
├── README.md
├── .gitignore
├── data/
│   ├── raw/
│   ├── interim/
│   └── processed/
├── notebooks/
├── src/
├── outputs/
│   ├── figures/
│   └── tables/
├── docs/
│   ├── data_dictionary.md
│   ├── decisions.md
│   └── project_notes.md
└── tests/
```
## What I like about it
What I particularly like about this layout is the docs folder, especially the data_dictionary.md file. How many times have you started looking at data and thought, "Why is there no data dictionary????" I know I've thought this, but have not be the greatest at actually creating them either. Having a documentation folder as part of a standard layout puts it right in your face - less easy to forgot that you need to document!
